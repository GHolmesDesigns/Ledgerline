# Ledgerline logo

G.Holmes Designs CMYK family, made specific to the app.

- **Concept:** a house outline holds the three GHD registration circles and sits on an accounting double rule, the line under a ledger total. The yellow circle is on top as the Florida sun, and cyan (the coast) and magenta sit below.
- **Color:** Near Black `#101820`, Cyan `#00A0F0`, Magenta `#E80078`, Yellow `#F8E000`. On light backgrounds the overlaps are drawn as flat multiply mixes. In the reverse version they are screen mixes. Everything is real geometry, with no blend modes, so the files import cleanly into Affinity and Figma.
- **Type:** wordmark in Outfit 700 at -0.035em, descriptor in DM Mono 500 at +0.14em. Both are converted to outlines.

| File | Use |
|---|---|
| ledgerline-lockup.svg | App header (replaces the CSS three-circle `BrandMark` + text) |
| ledgerline-lockup-descriptor.svg | Primary lockup: docs, README, splash |
| ledgerline-lockup-reverse.svg | Near Black backgrounds |
| ledgerline-mark.svg / -reverse.svg | Mark only: empty states, loading |
| ledgerline-app-icon.svg / -dark.svg | PWA / home-screen icon |
| favicon.svg | Browser tab. Heavier stroke and a single rule for 16–32px |
| png/ | Raster exports (favicon 16/32/48, app icon 180/192/512/1024, lockups at 1200w) |

Minimum sizes: full lockup 120px wide; mark 20px; under 20px use favicon.svg.
Clear space: the height of the house roof (about ¼ of the mark height) on all sides.
